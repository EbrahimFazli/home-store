# جلسهٔ ۱ — معرفی درس مهندسی نرم‌افزار

## فایل‌ها
- `session-01.md` — اسلایدهای Marp (منبع اصلی)
- `session-01.pdf` — خروجی PDF (به‌زودی)
- `images/` — تصاویر اسلایدها

## نحوهٔ استفاده

### ۱. با VS Code
1. افزونهٔ **Marp for VS Code** را نصب کن.
2. فایل `session-01.md` را باز کن.
3. `Cmd + K V` را بزن تا پیش‌نمایش ببینی.
4. برای خروجی: Command Palette → `Marp: Export Slide Deck` → PDF.

### ۲. با مرورگر
1. برو به [web.marp.app](https://web.marp.app).
2. محتوای `session-01.md` را پیست کن.
3. خروجی PDF بگیر.
